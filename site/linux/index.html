Path of Exile 2 on Linux

PoE2 on Linux with Proton, with the item overlay.

Playing Path of Exile 2 through Steam with Proton, Lutris or Heroic? PoE Upgrade Checker has a Linux AppImage (experimental): hover an item, press F2, and Path of Building says what it does to your build, right next to the item.

Download the AppImage Linux notes on GitHub

Setting it up

It's made for desktop Linux with the game running through Steam Proton (or Lutris or Heroic): Ubuntu, Fedora, Arch, Bazzite and so on, on X11 or Wayland.

  1. Download PoE-Upgrade-Checker.AppImage from the newest release and keep it where you want it, for example ~/Applications.
  2. Make it executable and run it: right-click → Properties → Allow executing as program, or chmod +x PoE-Upgrade-Checker.AppImage and start it. Some distros need FUSE for AppImages (for example sudo apt install libfuse2 on Ubuntu 22.04 and newer).
  3. In game, use Windowed Fullscreen, hover an item and press F2.

It updates itself like the Windows version. The file keeps its name, so your shortcuts and Start with your desktop keep working.

How it works under Proton

  • Path of Building runs inside the app, the same engine as on Windows, so the verdicts are the same. You don't need Path of Building installed or running under Wine.
  • Copying the item: the app sends one Ctrl+C to the game through X11's XTest, using the python3 almost every distro has. The game runs under Proton as an X11 window, so this works on Wayland desktops too, through XWayland. If that's missing it uses xdotool, and failing that you can press Ctrl+C on the item yourself: the app picks it up from the clipboard.
  • The F2 hotkey works while the game is focused. On some Wayland desktops global hotkeys don't reach native Wayland windows, which doesn't matter in game.
  • Your loot filters and Client.txt: under Proton the game keeps its Documents folder inside Steam's own folder (steamapps/compatdata/2694490/pfx/…), not in your home folder. The loot filter editor and League start look there, in every Steam library, by themselves. Filters somewhere else? Use Change folder in the loot filter editor.
  • Steam Deck: desktop mode works like any Linux desktop. Gaming mode doesn't allow other windows over the game.

What you get in game

Everything the Windows version does: item upgrade verdicts from Path of Building, trade searches weighted for your build, price checks with poe.ninja prices and what sold, map and waystone checks, and the league start route, for Path of Exile 2 and Path of Exile 1. See all features, or read about Path of Building for PoE2.

Linux support is experimental. Not working for you? Open an issue with your distro, desktop (GNOME, KDE…), X11 or Wayland, and the log (tray → Open log file). The overlay never reads game memory or changes game files. It's a fan project, not affiliated with Grinding Gear Games or Valve.

Questions

Does the overlay work with PoE2 under Proton?

Yes, experimentally. The Linux AppImage is made for Path of Exile 2 running through Steam with Proton, or through Lutris or Heroic, on X11 or Wayland desktops. Windows 10 and 11 are fully supported.

Does it work on Wayland?

Yes. The game runs under Proton as an X11 window through XWayland, and the app runs as an X11 app too, so the F2 hotkey and the popup work in game. On some Wayland desktops global hotkeys don't reach native Wayland windows, which doesn't matter while you play.

Does it work on the Steam Deck?

In desktop mode it works like on any Linux desktop. Gaming mode doesn't allow other windows over the game, so the popup can't show there.

Is it safe to use on Linux?

It works the same as on Windows: it never reads game memory or changes game files, and its only input to the game is one Ctrl+C per key press, the same as copying an item yourself. It's a fan project, not affiliated with Grinding Gear Games. More in Fair play and privacy.
